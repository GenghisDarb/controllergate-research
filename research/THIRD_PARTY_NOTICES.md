# Source attribution and publication scope

The dated exports contain the project’s own reports, analysis, code, calculations and result receipts, together with the attributed source-code excerpts listed below. They contain no copied third-party journal PDFs, full articles, raw interview recording, video frames or full interview transcript. The two PNG figures in the exports were generated by the project’s own numerical analyses.

## Spot-On author example

The unchanged `research/SpotOn_main.m` and `research/spoton_matlab_README.md` in the 23 November export are from the [publisher’s archived Spot-On Matlab repository](https://github.com/elifesciences-publications/spot-on-matlab/tree/f155c4c889ea124a8f55ab8f620e540628e18f92), pinned at commit `f155c4c889ea124a8f55ab8f620e540628e18f92`. The source header credits Anders Sejr Hansen and Maxime Woringer, 2017. It grants GPL version 3 or later and includes a Matlab linking permission. The unchanged repository license is retained as `research/SpotOn_LICENSE.md`. These files are preserved as separately attributed source material; the project does not claim authorship of them.

Associated article: Hansen AS, Woringer M, Grimm JB, Lavis LD, Tjian R, Darzacq X. *Robust model-based analysis of single-particle tracking experiments with Spot-On*. eLife 2018;7:e33125. [doi:10.7554/eLife.33125](https://doi.org/10.7554/eLife.33125).

The two raw CTCF MAT inputs used in the completed local analysis are **omitted from this public derivative**. A separate data redistribution license was not verified from the inspected repository README/license or parsed [dataset record](https://zenodo.org/records/834781). This does not assert that reuse is forbidden. The project preserves its original input hashes, source paths, analysis specifications and results, and provides `research/retrieve_ctcf_inputs.py` to retrieve those exact inputs from the original publisher source. Existing scientific inputs and results were not modified by this packaging decision.

## Reactome

The selected reaction contract is a project transcription of the six cited official Reactome records; it is not an original Reactome JSON or SBML export. The [official Reactome license](https://reactome.org/license), checked on 23 November 2026, places database data and derived data files under CC0. This export retains event identifiers and source URLs. It does not redistribute pathway illustrations, branding or Reactome application code.

## ControllerGate sources and private exclusions

Historical ControllerGate source excerpts are from the named public repository versions recorded in the manifests. They remain historical source evidence, and the project’s current corrections do not silently alter their contents.

The public derivatives omit the raw private project-definition excerpt, private Guide receipt, uploaded-media identity receipt and original raw media. Old project-authored report prose retains a statement that the Guide was read and its read/version date; no Guide text, private document URL, account credential or live task-board content is included. See each `PUBLIC_EXPORT.json` for the exact excluded paths. These are scoped derivative archives, not replacements for the original delivered private packages.
