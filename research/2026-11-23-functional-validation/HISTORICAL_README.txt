COMPLETED RESULTS

1. Six directed Reactome events were manually transcribed from official records.
   A faithful atomic ControllerGate adapter and an equally informed generic
   interpreter agree with the declared source model in all 12,150 event-local
   cases. The deliberately lossy diagnostic variants expose resource, catalyst
   and compartment failures. These are synthetic finite inventory cases, not
   biological frequency estimates.

2. Both competent implementations agree on all 108 ordered two-action batches.
   Independent initial-snapshot approvals overcommit in 16 batches. This is a
   sequential model test, not a real database or thread-concurrency test.

3. Exact stoichiometry verifies cofactor-projection return while the full material
   state changes. Elementary information-loss bounds identify state distinctions
   required for a specified target. This is not a new TLD notebook result.

4. Two real author-provided CTCF records were analyzed. The tested mixture gains
   0.615888 and 0.877488 nats against the primary single-component model on heldout
   rep1 trajectories and a rep3 cell without refitting. A separately frozen,
   post-result free-Gaussian sensitivity retains gains of 0.624185 and 0.877628.
   These are trajectory-average marginal log scores, not accuracy percentages.
   This does not reproduce full Spot-On or identify physical molecular states.

5. The current-source evidence candidate was advanced through actual imported
   functions and CLI paths. Final results_v6 passes 42 test methods, including
   eight unchanged original source tests. Fifteen actual CLI calls exercise the
   pipeline over 12 explicitly synthetic receipts across six cells, with 90
   arm/program executions and all 70 registry cells accounted for. Zero causal
   sensitivity or ownership claims are made. Two real local Audioread source and
   project-harness executions are recorded separately.

6. Independent checks reconstruct all source-token cases and batches, recompute
   raw-data scores with a separate parser/density implementation, and reject all
   eight final targeted execution-binding mutations. Initial failed integration
   attempts and review findings remain preserved.

SAFE REPRODUCTION

Keep this archive unchanged. Work in an extracted COPY if rerunning scripts that
write receipts or deterministic outcome files. Use ordinary Python, without -O;
the frozen research scripts include assertion-based integrity checks.

First, from the extracted package root:
    python verify_package.py

Mechanism tests use the Python standard library. In a disposable copy, from
mechanisms/:
    python -m unittest test_translation -v
    python run_benchmark.py
    python legacy_witnesses.py
    python verify_artifacts.py

Source-direct review, from a disposable package root:
    python formal/independent_transition_review.py
    python formal/check_coupled_invariants.py

Real-data analysis requires NumPy, SciPy and Matplotlib. The precise safe replay
layout and commands are in research/ctcf_reanalysis/README.md. The primary and
sensitivity scripts refuse to overwrite their original outputs. New completion
times change full output hashes; compare scientific values at stated tolerance.
The independent score review is:
    python formal/independent_ctcf_review.py

The integration candidate has its own detailed README and final source manifest.
Its recorded replay requires Python 3.12 and Git; Git creates a local fixture for
the actual source-capsule schema test.
From a disposable package root, select a fresh output directory:
    python integration/run_integration_checks.py --output /tmp/controllergate-replay-unique

Patch applicability was checked against the pinned source subset. This package
is a local candidate, not a deployed full repository checkout. The applicability
receipt and original source are included for review.

The PDF build requires ReportLab and DejaVu fonts and writes the report in
deliverables/:

The package was also checked after relocation, with both CTCF seals, raw MAT
parsing and CLI entry points invoked from an unrelated working directory. This
verifies relocation on the recorded runtime, not installation on a clean machine.
