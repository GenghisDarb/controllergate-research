# Functional translation experiment — design before outcome access

This experiment addresses preservation of a declared transition system, not biological naming. The prior neutral-label comparison does not test Brad's stronger hypothesis about faithfully transferring biological structure, mechanism and environmental constraints.

## Question

Can the source-bound ControllerGate rehearsal path preserve the enabling conditions and resource changes of a small, source-grounded reaction network? Which information is lost before execution, and does a typed, atomic local translation repair that loss?

## Source selection

The source selection is coordinated with the independent research agent before model evaluation: the curated forward and reverse LDH events (R-HSA-71849 and R-HSA-70510), plus the forward and reverse lactate/proton transport events (R-HSA-373875 and R-HSA-373867) if their official participant details are accessible. Each directed event keeps its own identity. No reverse direction will be inferred merely from a narrative sentence or a generic reversible flag.

The official source transcription and its exact limitations will be frozen with the experiment. If export bytes are unavailable, a human-readable extraction is not to be called an original XML download. No fitted rate, diffusion coefficient, kinetic constant, concentration or observed cell trajectory will be invented.

## Declared model

The test model will be an untimed token transition system with identified, compartment-qualified resource places. Reactants are jointly required and consumed in source-declared multiplicities; products are added. A catalyst read condition denotes a supplied assertion of availability of the catalytically competent machinery for this modeled action; it is retained across successful actions. This is an explicit abstraction, not the assertion that mere enzyme abundance proves activity, or that the uncatalyzed physical rate is exactly zero.

Separate physical entities in separate compartments remain separate resources. An exported entity set may be represented as a single declared availability predicate; its internal composition or assembly dynamics are then outside the tested isomorphism. Negative regulation will not be turned into a hard inhibitor without an explicit source rule. Rate and completion-time questions remain UNRESOLVED.

## Comparison arms

1. **Source oracle:** direct independent interpretation of the frozen token contract.
2. **Faithful local translation:** a typed compiler and atomic resource transaction, reusing the archived resource-underflow primitive on private per-resource working state before committing a whole operation.
3. **Competent generic equivalent:** an independently written incidence/read-arc interpreter with exactly the same places, coefficients, catalyst availability and compartment information.
4. **Edge-only ablation:** deliberately replace joint reactant enabling with any-input connectivity. This is a mechanism-removal control, not a competent general baseline.
5. **Independent-prerequisite ablation:** independent approvals without joint resource reservation for simultaneous requested operations. A batch can overcommit shared resources; this is a separate concurrency test.
6. **Wrong-mechanism ablation:** consume a reusable catalyst. First-step success can agree while future behavior diverges.
7. **Compartment-collapse ablation:** pool copies of the same chemical across compartments; retain explicit counterexamples rather than interpreting pooled abundance as local availability.

The archived source-bound rehearsal is audited separately under its actual conformance meaning. Its PASS will not be relabeled as a physical-reaction acceptance claim the code never made.

## Frozen evaluation and reporting

After source assembly and implementation, freeze all code and input hashes before opening outcome files. Use a predeclared finite state grid and fixed short action sequences, not a search over tasks chosen to make the new compiler win. Report enabling agreement, exact successor-state agreement, resource invariants, repeated-action behavior, atomic-batch conflicts and all generic/faithful ties. Equal information, same requested actions and bounded work apply to both competent implementations.

The strongest eligible conclusion is that a particular translation preserves a particular declared source-derived model. No result here establishes a complete living-cell isomorphism, Reactome superiority over an equally informed generic solver, new provider performance, causal ownership, deployment authority or a physical TORUS/TLD result.
