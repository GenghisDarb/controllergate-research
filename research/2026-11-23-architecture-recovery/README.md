## Reproduce without changing the recorded outputs

The original experiment refuses to overwrite its results. The verification entry point below verifies package hashes and, with `--rerun-observers`, copies the experiment to a temporary directory before executing it and the independent review.

```bash
python -m pip install -r requirements-research.txt
python verify_package.py
python verify_package.py --rerun-observers
python archive/dimensions/check_ghost_definitions_portable.py --output-dir /tmp/torus-ghost-fresh-run
```

Choose a new ghost output directory on every run. The portable ghost script records the archived source hash as provenance by default; it does not claim to recheck unavailable private bytes. Supply `--archive-source PATH` if you possess the original, and it verifies the pinned hash. The original ghost script is retained unchanged for execution custody and expects its historical source path; use the portable derivative for a public checkout.
