# Research interpretation failures: cause, fix and detection

This playbook records actual failure modes encountered in this research recovery. It does not grant release authority or replace an experiment's specification.

| Failure | Root cause | Repair completed | Detection elsewhere |
|---|---|---|---|
| Declaring no TLD connection from absence of one ladder endpoint | A narrow diagnostic was allowed to exhaust the historical vocabulary | Withdrew the categorical exclusion; recovered broad closure history; implemented a specific role-inspired mapping | Require the sentence to identify which endpoint and which functional relation it excludes |
| Stopping at an early conceptual or failed stage | First matching artifact was mistaken for the end of development | Preserved later ancilla repair, implemented ToT work and XIV endpoint corrections with source spans | Follow later source versions and receipts before labeling a capability absent or a failure unresolved |
| Treating three catalyst assertions as three proven shell roles | Cardinality was substituted for functional correspondence | Separated catalytic context from proposal/reconciliation/certification services; tested the latter | Require a role map, transition correspondence and removal/control test, not only equal counts |
| Treating unchanged outputs as full closure | Hidden context and projection fibers were omitted | Enumerated observer ambiguity and tested explicit catalyst-off intervention | Track state context; compare full state with projection; test stopping by starvation or missing permission |
| Treating multiple views as independent evidence | Shared model/data origin was ignored | Classified the new benefit as complementary observation, and checked all coordinate triples | Record common source hashes; test joint identifiability separately from statistical replication |
| Treating a positive pair proxy as proof of superadditivity | The baseline was worse-single rather than an additive contrast | Preserved original proxy but corrected its interpretation | Test an additive counterexample; declare outcome scale, baseline and uncertainty |
| Keeping an attractive ghost number after changing its definition | Nome, function value, normalization and argument were conflated | Recomputed eta, proved chi10 zero at the archived point, separated the coupled replacement | Record function, argument and normalization together; audit descendants and special points |
| Losing valid work when a stronger claim fails | One unsupported interpretation was used to dismiss a whole calculation | Reconstructed the partition plateau and preserved successful transition tests alongside limits | Evaluate each numerical result and interpretation separately |
| Calling a saved receipt a fresh execution | Custody and execution were conflated | Labeled prior replays, new local runs, independent reconstruction and source-only history separately | Require run time, code/input hashes, environment and actual output for a new-execution claim |

The experiment supplies bounded evidence of source conformity and observer complementarity. The historical ledgers establish what the project said and later changed. Neither kind of evidence alone proves biological superiority or physical unification.
