# Claim boundaries

Current evidence supports a bounded research-harness claim only.

Allowed statements:

- ControllerGate is a provenance-first software repair research harness.
- One confirmed external non-Ansible repair episode is recorded so far.
- v2.37 introduces shared gates, a reusable workflow, a consolidated state format, and a clean replication protocol.

Blocked statements:

- Full scoring is not run and remains disallowed.
- Memory lift is not demonstrated on external real bugs.
- Self-maintaining software is not demonstrated.
- Public technical-validation readiness is not claimed.

Any broader claim requires additional audited external repair episodes and accepted matched-null evidence.
