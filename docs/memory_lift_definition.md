## Batch079 finite-sample clarification

ControllerGate distinguishes an executed randomization null from a negative control, memory ablation, and strong deterministic software baseline. Candidate-level empirical tails use `(1 + exceedances) / (B + 1)`. Eight or sixteen unique null executions are smoke-test depth only; a 0.95 candidate threshold requires at least nineteen unique executed randomization-null sequences. Z scores remain descriptive and cannot replace the empirical tail. Degenerate null variance fails closed. Batch079 produced no candidate-level memory-lift estimate because its incident frame admitted no candidates.

Memory lift remains not demonstrated. The later Batch080 boundary supersedes the historical Batch021 status for current reporting.
