# ToT-BULB Environment Volume

The software-lane volume uses contact role, environment/provider dimension, runtime phase/failure depth, and optional evidence epoch as coordinates. It builds a global capability mask before candidate work and a candidate mask only after identity is established. Coupled ToT-BROT evidence selects sparse basins. Blind Cartesian sweeps are excluded from claim-bearing runs.

The active Nbclient basin covers the exact runtime build, distribution identity, package epoch, warning policy, runner/plugins, target origin, and harness. Diagnostic warning suppression is non-authoritative localization only.
