# Roadmap to v3

v3 readiness is not claimed in this run.

Required before a technical-validation claim:

- shared core package passes tests,
- reusable workflow is active,
- artifact packaging hygiene passes,
- workspace transport integrity gate is active,
- native and issue-derived evidence classes remain separate,
- clean replication protocol can run without new version-specific lanes,
- at least three scoreable external repair episodes are recorded,
- at least two distinct repositories are represented before generalization claims,
- matched-null comparison reaches the accepted separation threshold before any memory-lift claim,
- full scoring remains disabled unless explicitly authorized,
- self-maintaining software remains not demonstrated.
