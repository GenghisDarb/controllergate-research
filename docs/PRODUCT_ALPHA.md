# ControllerGate Product Alpha

ControllerGate Product Alpha is an installable, credential-free research runtime for evidence-bound controlled maintenance. The canonical `controllergate` CLI owns run state, checkpoints, resume, verification, historical canary execution, health observation, rollback drills, and read-only connector verification.

The included fixture demonstrates a complete controlled cycle and safe abstention. It is not a production-readiness, autonomous-maintenance, or live-write claim. The validated protocol remains v2.19; full scoring is disallowed and write-capable connectors are inactive.
