# Evidence levels

| Level | Meaning | May authorize |
|---|---|---|
| Source custody | Exact bytes, commit, tree, or bundle verified | Parsing and acquisition only |
| Contract custody | Truth-blind candidate command and provider contract sealed | Candidate materialization only |
| Typed observation | Raw process or structured product captured | Semantic verification input |
| Verified incident | Independent verifier confirms the declared incident | Frozen-cohort/topology eligibility |
| Causal topology | Source/runtime contacts and uncertainty regions have raw parents | Probe planning only |
| Provisional causal fact | Executed probe and independent verifier support a scoped state | Truth maintenance only |
| ControllerAudit terminal | Alternatives and contradictions are resolved or evidence is exhausted | Source-ownership stages when the terminal is source-owned |
| Source-ownership proof | Executed producers and independent verifiers establish direct contact and exclusions | Repair-license prerequisites only |
| Human-authorized repair license | Candidate, run, frame, path, patch, nonce, and expiry are bound | One protected actuation |
| Validated repair episode | Source-only patch, unchanged tests, validation, duplicate replay, and count gate pass | Bounded evidence/count update |

No lower level inherits the authority of a higher one. Agreement among topology, shadow TLD metadata, and modalities does not itself establish source ownership.
