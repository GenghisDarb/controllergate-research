# ControllerGate v1.7-alpha Memory Store

This directory is reserved for discovered real-trace memory.

Do not seed this store from v1.6 synthetic or controlled benchmark labels.

Allowed sources:

- earlier real maintenance episodes;
- evidence-derived failure signatures;
- decision-time artifacts;
- validated agent/tool traces.

Forbidden sources:

- future outcome labels before the episode decision point;
- hidden downstream results before decision;
- benchmark-only family labels;
- human correction summaries that were not available to the agent at decision time;
- v1.6 controlled benchmark recurrence labels.
